# Peduli Abu Vulkanik

Halaman kampanye "Bersama Peduli, Bersama Kuat" dari Fazlanova Generation tentang cara menjaga diri dan lingkungan saat hujan abu vulkanik.

Live: https://fazlanovabersama.vercel.app

Isinya tips praktis: pakai masker, jaga makanan dan minuman, kurangi aktivitas di luar, tutup ventilasi rumah, dan segera periksa kesehatan bila ada keluhan.

Satu berkas `index.html` dan bisa dipasang sebagai PWA (`manifest.json`).
